This is a copy of my Internship at Energize Capital, I automated Energize's sourcing pipeline by implementating a webscrapper 
that reads through multiple newsletters that announce funding rounds for start ups to build a dynamic database of companies.
Connected a custom build GPT tool with the database through an API that allows for semantic search based on the meaning of the 
querry (cosine similarity) and structured filtering (on dates, money raised, etc)
